# Marketplace Listing - Bulk Update Pro

## App Name
Bulk Update Pro

## Short Description (max 150 characters)
Update multiple board items at once. Select items, choose a column, set the new value, and apply changes in bulk.

## Long Description

### Overview
Bulk Update Pro is a powerful board view app that saves you hours of repetitive work. Instead of clicking through items one by one, select multiple items, choose your column, set the value, and update everything with a single click.

### Key Features

**Easy 3-Step Process**
1. Select the items you want to update (with search and filter options)
2. Choose the column and enter the new value
3. Preview your changes and confirm

**Comprehensive Column Support**
Update virtually any column type in your board:
- Status, Dropdown, and Tags
- Text and Long Text
- Numbers and Ratings
- Date, Timeline, and Week
- People assignment
- Email, Phone, and Links
- Location and Country
- Time/Hour and World Clock
- Checkbox and Color
- Board Relations

**Smart Filtering**
- Search items by name
- Filter by column values
- Select all or pick specific items

**Safe Updates**
- Preview all changes before applying
- Visual progress tracking during updates
- Clear confirmation before any changes are made

**Native Integration**
- Seamless Monday.com look and feel
- Full dark mode support
- Works with any board structure

### Use Cases
- Mass-assign tasks to team members
- Bulk update project statuses
- Set dates for multiple items
- Update contact information in bulk
- Standardize values across items

### Who Is This For?
- Project Managers handling large boards
- Team Leads assigning work in bulk
- Operations teams maintaining data consistency
- Anyone tired of repetitive clicking!

## Permissions Explanation

**boards:read** - Required to read your board's items and columns

**boards:write** - Required to update column values when you confirm changes

**users:read** - Required to show available users for People column assignments

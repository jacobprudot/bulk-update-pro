## Long Description

**Bulk Update Pro** makes mass-editing your Monday.com boards fast and effortless.

### Key Features:
- **Multi-Select Items**: Choose multiple items at once using checkboxes or select all
- **Smart Column Support**: Works with 20+ column types including Status, Date, People, Dropdown, Tags, and more
- **Live Preview**: Review all changes before applying them
- **Progress Tracking**: Visual progress bar shows real-time update status
- **Dark Mode**: Seamlessly adapts to your Monday.com theme
- **Error Handling**: Detailed feedback on successful and failed updates

### How It Works:
1. Select the items you want to update
2. Choose the column and enter the new value
3. Preview your changes
4. Confirm and watch the updates happen in real-time

### Supported Column Types:
Text, Long Text, Numbers, Status, Date, People, Dropdown, Email, Phone, Link, Checkbox, Timeline, Tags, Rating, Country, Location, Hour, Week, World Clock, Color Picker, Board Relation, and more.

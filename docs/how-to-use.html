Bulk Update Pro

Learn how to update multiple items in seconds

Getting Started

Bulk Update Pro is a Board View that allows you to update multiple items at once. After installing the app, you need to add it to your board:

  1. Open any board in monday.com
  2. Click the + button next to your existing views (Main Table, Kanban, etc.)
  3. Select Apps from the menu
  4. Find and click Bulk Update Pro
Tip: You can add Bulk Update Pro to multiple boards. Each board will have its own instance.

1 Select Items

The first step is to select which items you want to update. You have several options:

  • Select All: Click the "Select all" checkbox to select every item on the board
  • Individual Selection: Click on specific items to select them one by one
  • Search: Use the search box to filter items by name
  • Filter by Column: Use the column filter dropdown to show only items with specific values
Tip: The item count shows how many items you've selected. You can select parent items and subitems.

2 Choose Column & Value

After selecting items, click Next to choose what to update:

  • Select Column: Choose which column you want to update from the dropdown
  • Set New Value: Enter or select the new value for that column

Supported column types:

Status Date Text Numbers People Dropdown Email Phone Rating Checkbox Country Timeline

3 Review & Confirm

Before applying changes, you'll see a preview of all updates:

  • Review the list of items that will be updated
  • Verify the column and new value are correct
  • Click Apply Changes to execute the bulk update
Tip: You can go back to previous steps if you need to make adjustments before confirming.

Frequently Asked Questions

How many items can I update at once?

There's no hard limit. Bulk Update Pro can handle hundreds of items. For very large boards, updates are processed in batches to ensure reliability.

Can I undo a bulk update?

Bulk Update Pro doesn't have a built-in undo feature. We recommend using the preview step to carefully review changes before applying them. For critical boards, consider using monday.com's activity log to track changes.

Does it work with subitems?

Yes! Bulk Update Pro displays both parent items and subitems. You can select and update them together or separately.

Why can't I see certain columns?

Some column types like Formula, Mirror, and Auto-number are read-only and cannot be updated. Only editable columns appear in the column selector.

Is my data safe?

Yes. Bulk Update Pro operates entirely within monday.com's infrastructure. We don't store any of your data on external servers. All updates are made directly through monday.com's official API.
